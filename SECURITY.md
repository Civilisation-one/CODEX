# Security policy

CODEX holds documentation, not running code, but it describes security requirements that other Civilisation-one repositories implement.

## Reporting a problem

**Do not open a public issue for a security problem.**

- If GitHub's private vulnerability reporting is enabled for this repository, use **Security → Report a vulnerability**.
- Otherwise, contact the repository maintainer privately through GitHub before disclosing anything.

Please include the document ID and section (or the repository and file, for implementation issues), what you found, and how it could be exploited.

## Scope

- Errors or gaps in the security requirements in CODEX (for example CV1-PLATFORM-CODEX-002, H4).
- Places where an implementation in another Civilisation-one repository contradicts a CODEX security requirement.

Reports are acknowledged when received. Fixes to requirements are made through reviewed pull requests, as described in [CONTRIBUTING.md](CONTRIBUTING.md).
